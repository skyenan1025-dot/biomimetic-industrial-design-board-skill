# 创建仿生工业设计展板

## 概述

将生物灵感转化为一张结构完整、逻辑连贯的A3竖版工业设计展板。展现可信的“生物观察—设计转译—产品深化”过程，并以最终产品效果图作为视觉中心。

**必须调用的子技能：** 使用 `imagegen` 生成最终位图展板。

## 理解用户输入

| 用户输入 | 处理方式 |
|---|---|
| 仅提供仿生对象 | 自动选择在功能与形态上最匹配的产品；简短说明选择后直接生成，不追问。 |
| 仿生对象＋产品 | 严格采用二者。 |
| 参考图片 | 默认作为版式或风格参考；除非用户明确要求编辑原图。在提示词中标明每张图片的用途。 |
| 配色、材质或氛围 | 完整保留；仅补充缺失信息。 |

只有当仿生对象或产品确实存在歧义时才提问。

## 建立仿生转译逻辑

在内部识别3—5个可转化特征，来源可包括轮廓、结构、表面、运动、生长方式或适应机制。把每个特征映射到产品形态、机械结构、交互、材料或可持续策略。确保比例、关节、控制方式、材料与制造逻辑合理。提取生物原理，不要直接制作动物造型的趣味产品。

## A3固定版式

采用A3竖版比例297 × 420 mm（1:1.414）。使用严格网格、统一边距、细分隔线、编号板块、充足留白和自上而下的阅读顺序。过程部分约占55%—60%，最终设计约占40%—45%。

以下7个板块缺一不可：

1. **BIOLOGICAL ORIGIN｜仿生原型** — 生物及其栖息环境照片，配简短结构标注。
2. **FEATURE EXTRACTION｜特征提取** — 分析线稿，标出3—5项特征，并使用几何辅助线、箭头或运动轨迹。
3. **FORM EVOLUTION｜形态演变** — 4—6个相连步骤：生物原型 → 线条提取 → 几何抽象 → 产品轮廓 → 初始概念。
4. **FORM EXPLORATION｜造型推演** — 6—9张工业设计概念草图，变化比例、曲面、结构和交互；标出一个选定方案。
5. **DESIGN REFINEMENT｜设计深化** — 展示三视图、剖面、细节、CMF、材料或结构机制研究。
6. **FINAL DESIGN｜最终设计** — 全板最大画面；写实的产品3/4视角效果图，最多增加两张小视角或使用场景。
7. **DESIGN HIGHLIGHTS｜设计亮点** — 4—6项标注，覆盖适用的形态、功能、交互、工艺、可持续性与用户价值。

板块可以共用同一行，但不得合并消失或退化为装饰拼贴。

## 图片生成提示词协议

```text
使用场景：信息图/流程展板
资产类型：A3竖版仿生工业设计展板
核心任务：将[仿生对象]转化为[产品]
输入图片：[图片及其用途，如有]
仿生映射：[3—5项“生物特征 → 设计转译”]
版式：完整呈现7个固定板块，最终产品效果图占据视觉中心
最终效果图：[视角、场景、材料、结构与光线]
风格：专业工业设计作品集，克制、现代、具备制造可行性
配色：中性基础色＋从生物中提取的一种强调色
准确文字：标题、编号、7个简短的英文板块标题
约束：严格网格；演变过程清晰；草图与效果图保持同一产品造型；留白充足
避免：长段文字、乱码、卡通生物、直接照搬生物外形、装饰拼贴、随机零件、不合理结构、过度科幻、Logo、水印
```

图片模型难以稳定生成大段准确文字，因此只保留简短英文标题。不要承诺生成图片中的长篇正文能够完美排版。

## 生成与检查

1. 调用内置图片生成器，不要只返回提示词。
2. 若有参考图，只传入覆盖全部参考所需的最少图片数量。
3. 除非用户要求多个方案，否则生成一张精修展板。
4. 检查仿生对象、7个板块、连续演变、选定方案、主效果图、A3层级和明显乱码。
5. 若关键板块缺失或产品造型前后漂移，针对问题追加一次修正生成。
6. 返回图片，并简短说明产品选择、配色和主要仿生映射。

| 基调 | 暖白或浅灰＋一种生物强调色 |

## 常见问题

- 只生成情绪板 → 恢复完整的形态演变链条。
- 最终产品与草图无关 → 重复选定轮廓与仿生映射。
- 过程区过于拥挤 → 先缩短标签，不要先缩小草图。
- 直接复制动物外形 → 转译折叠、弯曲、肋状支撑、气流或生长等原理。
- 声称“可直接印刷” → A3只是版式目标；只有用户另行要求时才制作精确生产文件。
